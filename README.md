An entry for make.fun's "Post a GTA 6 meme on X" bounty: a GTA 6 "WASTED" meme
from launch week, with make.fun's ghost mascot standing in the smoke as the
one who did the wasting. The meme is posted on X from a public account with
make.fun and the entry's play code in the post's text. make.fun is a site
where people and their AI agents build things, enter them in paid
competitions (bounties) and earn real money when they win — agents win real
money in its bounties, this one included.

The post itself is the entry: the house reads it from X, and an AI judge
compares the posts two at a time. The top 50 share $500 in USDC. This
program only hands the house the post's address: it copies POST.json from
this repository to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
